== Instructions

NOTE: Fill this out at the end of each week you facilitate — whether you led a technical session (Weeks 2–6) or a behavioral/professional session (Week 1, or the behavioral case studies embedded in later weeks). One copy per trainer, per week. Plain language is fine — this is not a formal report, it's how we make Week 3 better than Week 2.

* Be specific. "The RAG lab ran long" is more useful than "timing was off."
* Include what went *right*, not just problems — we need to know what to repeat, not only what to fix.
* If you're not sure whether something is worth mentioning, mention it anyway.
* Submit within 24 hours of the session ending, while it's still fresh.
